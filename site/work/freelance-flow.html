One place for a freelancer's tasks, time and invoices.

A personal project: a web app that replaces the mix of task, time and payment tools a freelancer juggles every day.

Type
Personal project, written up as a case study
Role
Designer
Scope
Web app: dashboard, project board, time tracking and invoicing
Year
2025

Problem

Freelancers often work across separate tools for tasks, spreadsheets for time and a payment platform for invoices. None of them talk to each other, so hours go unlogged, invoices get missed and money becomes stressful to track.

Who it is for

I designed around one example freelancer: Alex Carter, a 28-year-old graphic designer who uses Trello for tasks, Google Sheets for time and PayPal for invoices. Alex is a persona I created to focus the design, not a real person.

  • Switching between apps to manage tasks, time and invoices
  • Forgetting to log hours, and under-billing as a result
  • Losing track of unpaid invoices
  • Wanting one affordable tool that cuts admin

Mapping the product

Before any screens, I mapped how Alex moves from starting the day to getting paid, then wireframed each step of that flow.

A day with FreelanceFlow

The design is told through Alex's week. Each step below is a screen in the app.

Starting the day

Alex lands on the dashboard: upcoming deadlines, outstanding invoices, earnings this month, and today's tasks in one view.

Working on tasks

A Kanban board with Backlog, In Progress and Completed columns. Alex drags a task across, adds a note and starts a timer without leaving the page.

The project board helps Alex see work across stages at a glance.

Tracking time

The running timer sits on the dashboard. When Alex stops it, the time logs to the right project, and the Time Tracking tab shows the week's totals and billable time.

Creating an invoice

On Friday, Alex picks a project, pulls in the logged hours and the form totals itself. One click creates the invoice.

Invoices are built from logged time, so nothing is retyped.

Reviewing an invoice

When a client asks for a copy, Alex finds the overdue invoice, opens its details, downloads the PDF and sends it, all without leaving the platform.

Statuses make overdue invoices easy to spot.

Planned next step

The next iteration I designed is automatic time tracking: an Integrations tab that connects tools such as Figma, Photoshop, VS Code and Google Docs, so a timer starts when work on a project begins. AI would suggest which project each session belongs to, and the user would review it.

Needs and goals

  • Efficiency: less manual entry
  • Clarity: colour-coded statuses and progress bars
  • Financial control: quick review and sharing of invoices
  • Retention and growth: a single, affordable tool with room for integrations
